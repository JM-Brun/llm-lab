# Reports

Publish concise experiment reports with:

- the question and baseline;
- the exact command/configuration and data provenance;
- primary and supporting metrics;
- runtime and hardware context where relevant;
- error analysis, uncertainty, and limitations;
- links to code and machine-readable outputs.

Do not commit checkpoints, private data, or large generated artifacts. Use the experiment protocol in [docs/experiment-protocol.md](../docs/experiment-protocol.md).
