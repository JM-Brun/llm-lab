Distinguer mémoire des tables RoPE et cache KV

Réglez les paramètres d’une couche. Réduire la fraction rotative diminue les tables cosinus/sinus, mais ne réduit pas automatiquement les tenseurs K et V stockés dans le cache KV.

Tables cos/sin RoPE
Cache KV (K + V)
Rapport cache KV / tables
Dimensions rotatives

Estimation pour une couche : tables cos/sin = 2 × séquence × (dimensions rotatives / 2) éléments ; cache KV = 2 × batch × séquence × têtes KV × dimension complète de tête. Le calcul suppose que K et V restent de pleine largeur dans le cache. Il exclut surcoûts d’allocation, alignement, réplication et autres buffers. La quantification du cache KV est une hypothèse de taille par élément, pas une description d’un format précis.
